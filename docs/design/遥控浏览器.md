# 遥控浏览器（面板手动开网页）

状态：实施中（2026-11-07）

## 目标

在"浏览器"面板里，用户不经过 AI Agent，直接输入网址在服务器（本机）上打开网页，看到实时画面，并用手指点击、滑动、输入。用途：在手机上访问电脑才能访问的局域网页面（路由器后台、NAS、本机 dev server 等）。

## 范围

- 后端：`server/modules/browser-use/` 新增"手动会话"（manual）能力与控制路由；面板既有 agent 会话监控行为不变。
- 前端：`src/modules/browser-use/BrowserUsePanel.tsx` 新增打开入口与遥控视图；`src/shared/api.ts` 补端点。
- i18n：`settings.json` 的 `browserUse.*`（en / zh-CN / zh-TW，其余语言回退英文）。

不做：CDP 视频流（screencast）、多标签 UI、右键/双击、文件下载、`file://` 协议。

## 方案

### 会话模型

`BrowserUseSession.createdBy` 从 `'agent'` 扩为 `'agent' | 'manual'`，ownerId 用 `'user'`（与 `'agent'` 平级）。手动会话与 agent 会话同池：共用 TTL 回收（30 分钟无动作过期）、单 owner 上限、stop/delete、面板列表（来源用徽标区分）。

### 服务层（browser-use.service.ts）

- `createManualSession()`：要求 settings.enabled；viewport 1024x768（比 agent 的 1440x900 更适合手机缩放查看）；headless Chromium。
- 控制方法，均要求会话存在且 ready，动作后 `captureSession` 并返回 publicSession（响应自带新截图，前端免二次拉取）：
  - `manualNavigate(id, url)`：`normalizeManualUrl` — 无协议前缀补 `http://`（局域网地址友好，如 `192.168.1.1`），仅允许 http/https。
  - `manualNav(id, action: 'back' | 'forward' | 'reload')`。
  - `manualClick(id, {x, y})`：坐标必须为有限数字且落在 viewport 内，`page.mouse.click`；记录 cursor（actor `'user'`）。
  - `manualScroll(id, {deltaX, deltaY})`：值域 ±5000，鼠标移至视口中心后 `page.mouse.wheel`。
  - `manualType(id, {text})`：非空、≤2000 字符，`page.keyboard.type`（输入目标由先前的点击焦点决定）。
  - `manualPressKey(id, {key})`：白名单 Enter/Backspace/Delete/Tab/Escape/Arrow*/Home/End/PageUp/PageDown。
  - `getManualScreen(id)`：重新截图，返回会话公开字段。
- `stopSession` / `deleteSession` / `listSessions` 从仅 agent 扩为 agent + manual；agent 专属方法（MCP 路径）行为不变。
- 纯校验函数（`normalizeManualUrl`、坐标/按键校验）从服务导出供路由与测试使用。

### 路由（browser-use.routes.ts）

改为工厂 `createBrowserUseRouter(service)`（默认导出挂真实服务，`server/index.ts` 不变），全部在 `authenticateToken` 之后：

- `POST /sessions` 建 manual 会话
- `GET /sessions/:sessionId/screen` 实时画面
- `POST /sessions/:sessionId/navigate | nav | click | scroll | type | key`
- 新错误码：`SESSION_CREATE_FAILED`、`SESSION_CONTROL_FAILED`、`SESSION_SCREEN_LOAD_FAILED`

### 前端（BrowserUsePanel.tsx）

- 头部新增"打开浏览器"按钮（runtime available 时可用），创建后自动选中并进入全屏遥控视图。
- 选中 manual 会话时（内嵌与全屏同一视图）渲染遥控视图替代静态截图：
  - 地址栏（回车或 Go 提交）+ 后退/前进/刷新。
  - 画面区：点击换算视口坐标发 click；触摸滑动换算 wheel 发 scroll；动作响应直接更新画面。
  - 文本输入行：输入框发 type，附 Enter / 退格键钮。
  - 视图可见时 1.5s 轮询 screen；动作进行中暂停轮询。
- 坐标换算与滑动换算为纯函数，可单测。
- agent 会话视图与既有监控逻辑不动。

## 验证

- 后端：路由测试（假服务 + 真实 express 调用，覆盖成功/校验失败/服务异常三路）+ 纯函数单测（URL 规范化、按键白名单、坐标校验）。
- 前端：坐标/滑动换算纯函数 vitest 单测。
- `npm run typecheck`、`npm run lint`、`npm run build`。
- 真机遥控体验由部署后人工验收。

## 风险

- 任何登录用户可创建/遥控手动会话，并能借此访问服务器所在局域网。与现状同风险面（面板本就向登录用户暴露 agent 会话画面），单用户/家庭 LAN 场景接受；多用户共享部署需知悉。
- 轮询截图约每 1.5s 一帧 JPEG（百 KB 级），LAN 无压力，公网隧道下流量可感知。
- 手动会话与 agent 会话共享浏览器运行时与设置开关：设置里关闭 Browser 会同时停掉两者（沿用 `stopAllSessions` 行为）。
