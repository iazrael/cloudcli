# 流程图点击放大

> 状态：已实施
> 目标：md 预览和聊天里的 mermaid 流程图在手机上太小看不清，提供点击放大查看

## 方案

MermaidDiagram（`src/modules/code-editor/markdown/MermaidDiagram.tsx`）是聊天与 md
预览共用的 mermaid 渲染组件，SVG 已按容器宽度缩到很小。复用现成的
`UnifiedImageViewer`（聊天图片同款全屏查看器，自带双指缩放、拖拽平移、缩放按钮）：
渲染出的 SVG 转成 data URL，点击流程图打开查看器。

- SVG 根节点是 `width="100%"` + `max-width` 样式，转 data URL 时按 viewBox
  改写为显式宽高，查看器的 100% 缩放对应图的原始像素尺寸，object-fit 自动适配屏幕。
- data URL 而非 blob：免 revoke 生命周期管理；`<img>` 上下文不执行脚本，
  mermaid strict 模式输出，无注入面。
- i18n：`common:imageViewer.diagram` / `expandDiagram`，只补 en 与 zh-CN，其余 fallback 到 en。

## 验证

- 新增单测：渲染 mermaid 块 → 点击 → 出现全屏查看器（dialog + svg data URL）→ 关闭消失。
- `npm run test:client`、`build:client`、`typecheck`、`lint`。

## 风险

- mermaid 输出若解析失败，data URL 直接用原始 SVG 字符串兜底，不影响内嵌渲染。
