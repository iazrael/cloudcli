# 图片查看器黑白衬底切换

> 状态：已实施（2026-11-08）
> 目标：深色查看器里看不清浅色底图片（Mermaid 透明底图、白底截图）时，一键在黑/白衬底之间切换。

## 现场与原因

`UnifiedImageViewer` 弹窗背景固定为 `bg-black/90`。透明底、浅色笔画的图片（Mermaid 导出图最典型）直接隐形。图片本身没问题，缺的是一层可切换的衬底。

## 方案

- `ImageViewerSurface` 新增可选 `backdrop?: 'dark' | 'light'`：贴着图片的包装元素加纯色背景，`dark` 为黑、`light` 为白；不传保持现状（透明），供非弹窗内嵌使用。
- `UnifiedImageViewer` 工具栏在缩放组末尾、分隔线前加切换按钮（lucide `Contrast` 图标），状态默认 `dark`，与现有深色弹窗一致。弹窗骨架与工具栏配色不动，两种模式下都保持可读。
- 不做自动探测：透明 PNG 的角像素采不出可靠信息，手动切换结果可预期。

## 验证

- `src/shared/tests/UnifiedImageViewer.test.tsx`：新增切换测试，断言衬底在 `rgb(0,0,0)` 与 `rgb(255,255,255)` 间翻转，默认黑。
- 跑该测试文件 + `test:client` + `typecheck` + `lint` + `build:client`。

## 风险

- 无接口与协议变化；`backdrop` 不传时行为与旧版一致，`CodeEditorMediaPreview` 的内嵌用法不受影响。
