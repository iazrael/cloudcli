# 时间线虚拟列表 virtua 升级

状态：已完成，待部署

## 目标

修复聊天时间线在长寿命页面上的"消息错乱/空白/刷新无效"：用户视口底部渲染几十分钟前的旧行、直播行不进窗口、行间大片空白。

## 根因

virtua 0.52.9 的内部偏移映射在滚动交互累积后损坏（实测映射总高 16611px vs 真实内容 7959px，幻影 ~8600px），窗口按错误偏移取行。上游 0.52.10→0.54.0 的 #986（hidden/detached 后空白视口）、#1039（mount 前已滚动→空白）、#1045（shift 下布局损坏，正中 prepend shift 路径）正是同症状修复。消息数据链路（引擎 SQLite、API 分页、store 合并、直播帧）经实测全部有序，与此无关。

## 范围与方案

仅升级依赖 `virtua` 0.52.9 → ^0.54.2，不改任何业务代码。

## 验证

- chat 时间线三套件（sessionTimelineStore / sessionMessagePagination / sessionTimelineSequences）71/71 绿。
- dev 真会话验证渲染、直播贴底正常。
- 未做：长滚动+直播压测的幻影量化对比（遗留到部署后真机验收）。

## 风险

- virtua 0.53/0.54 含核心重构（store/cache/offset），滚动行为可能整体漂移；由 71 个时间线测试与真机会话冒烟兜底。
- 应用内刷新不重建 virtua 状态，部署后需整页重载（PWA 杀掉重开）才吃进修复。
