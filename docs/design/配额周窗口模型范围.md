# 配额周窗口按模型族区分

状态：已实现

## 目标

账号配额面板同时出现“全模型周配额”和“单模型周配额”时，标题能区分到模型族（如 Fable），与 Claude 官方 `/usage` 的 `Current week (all models)` / `Current week (Fable)` 对齐；不再是两行同名的“周配额”。

## 背景

Claude `/usage` 载荷同时返回 `seven_day` 与 `model_scoped`。2026-11-11 本机 Pro 账号实测：`seven_day` 9%，`model_scoped` 里 Fable 0%，官方 `claude -p "/usage"` 显示三条：Current session / Current week (all models) / Current week (Fable)。后端已按窗口建桶，但前端 `resolveBucketTitle` 把 `window === 'weekly'` 的桶一律显示成“周配额”，模型名丢失。因此不隐藏 Fable 窗口，只补模型范围。

## 范围

- `shared/protocol/quota.ts`：`ProviderQuotaBucket` 增加可选 `modelScope`，表示该窗口计量的模型族；全模型窗口不带。
- `server/modules/providers/list/claude/claude-quota.provider.ts`：`seven_day_opus` / `seven_day_sonnet` / `model_scoped` 映射时写入 `modelScope`。
- `src/modules/chat/modals/CommandResultModal.tsx`：周窗口标题按 `modelScope` 显示“周配额（Fable）”；同组存在单模型周窗口时，全模型窗口显示“周配额（所有模型）”。
- 已有 `cost` 段的 11 个语言文件补 `weeklyWindowScoped` / `weeklyWindowAllModels`。
- 同步 `docs/core/providers.md` 的配额载荷说明。

## 方案

1. 协议只加可选字段；旧客户端忽略后仍按原逻辑显示“周配额”，无破坏。
2. 后端不按套餐隐藏窗口：官方 Pro 账号仍显示 Fable 周条，隐藏会偏离官方。
3. 前端只在“同组有单模型周窗口”时给全模型窗口加后缀；Codex、ZCode、OpenCode 等没有 `modelScope` 的提供方保持原样。

## 验证

- 后端单测：Pro + Fable `model_scoped` 的 `modelScope`；Max + Opus/Fable 的映射；全模型窗口无 `modelScope`。
- 前端组件测试：渲染两份周窗口，断言“周配额（所有模型）”和“周配额（Fable）”。
- `npm run typecheck`、`npm run lint`、全量 client 测试与 provider 测试。
- 本机实跑 `fetchClaudeQuota`：Pro 账号返回 `claude-7d`（无 `modelScope`）与 `claude-7d-fable`（`modelScope: "Fable"`）。

## 风险

- 模型显示名来自服务端，Fable/Opus 等专有名词不进翻译；`{{model}}` 只做插值。
- 若未来某个提供方在同一组里同时给出多个单模型周窗口，每条都显示各自的模型名，不会互相覆盖。
