# 移动端输入框工具栏收纳

状态:实施中(2026-11-21)

## 目标

手机端输入框工具栏一行塞了 8~9 个控件(附件、语音、用量、斜杠命令、定时、模型、权限模式、Steer/旁路、发送),高频与低频操作混在一层。收纳后主栏只留高频入口,低频功能收进"＋"面板;桌面端(≥sm)保持现状不动。

## 范围

- `src/modules/chat/composer/` 下新增 `TokenUsageBadge.tsx`、`ComposerOverflowMenu.tsx`,重构 `ScheduleMessagePopover.tsx`(抽出内容组件)。
- `ChatComposer.tsx` footer 按 `sm:` 断点拆分移动/桌面布局。
- `PromptInput.tsx` 工具按钮移动端热区提升到 44px(`h-11 w-11 sm:h-8 sm:w-8`)。
- i18n:chat 命名空间新增 `input.moreTools`、`input.contextUsage`(15 种语言)。
- 不改后端、不改桌面端既有交互。

## 方案

主栏(移动端,顺序固定):`＋ 📎 [🎤] [87K!] | 模型 | 权限盾 [🫧旁路][⊕Steer] 发送`。发送固定最右;条件按钮(旁路/Steer)插入发送左侧,出现不移动发送键。

- **＋面板**:用量概览(点击进详情)、斜杠命令(带数量角标)、定时发送(无草稿置灰;面板内二级视图,含循环任务)、清空输入(有草稿才显)。复用定时弹层的内容(见下)。
- **用量徽标**:平时完全隐藏,used ≥85% 窗口显示、≥95% 变红(仍可点击进详情)。
- **权限模式**:不动。`usePermissionNameFit` 在窄屏已自动收成纯图标,颜色即模式(bypass 橙色),危险状态保持可见。
- **热区**:移动端工具/条件按钮统一 44px,桌面保持 32/40px。

定时弹层重构:`ScheduleMessagePopover` 把 portal 内的表体抽成 `ScheduleMessageContent`(状态内聚在内容组件,关闭后重置、下次打开重新播种"+1小时"),桌面弹层与移动面板共用同一内容;`onDone` 统一关闭。

## 验证

- 阈值逻辑先写测试(`tokenUsageAlert.test.tsx`):85%/95% 边界、无 total、used=0。
- `ComposerOverflowMenu.test.tsx`:条目按条件出现/置灰、用量行触发详情回调。
- `npm run test:client`、`typecheck`、`lint`、`build:client`。
- worktree dev(端口 3021/3022)以 390×844 视口人工/截图验收移动布局,桌面宽度回归确认不变。

## 风险

- 桌面/手机共用代码,改动必须严格限定在 `sm:` 断点内,桌面 DOM 仅新增一个隐藏的 ＋ 触发器。
- 条件按钮全出现(Steer+旁路同时)时最挤:靠模型 chip 收窄与 40px 条件按钮兜底,可接受。
- 定时弹层关闭后表单状态重置(原为保留),属行为微调,方向正确(重新播种时间)。
