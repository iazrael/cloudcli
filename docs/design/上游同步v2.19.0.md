## 待决策

开工前需要确认以下取舍；括号内是推荐项。

1. **工作区根只读开放（推荐：按上游开放，保留系统目录保护）**
   上游把 `WORKSPACES_ROOT`（默认用户主目录）和 `~/Downloads` 加入只读白名单，聊天里的 `file:` 链接可直接打开。上一轮同步曾因“默认根是 home、等于扩大读取范围”暂缓同类改动。上游现已加 `FORBIDDEN_WORKSPACE_PATHS` 保护：根落在系统关键目录时整体禁用并报错。若仍不接受 home 默认可读，则保留本仓库 `CLOUDCLI_EXTRA_READ_ROOTS` 方案，放弃上游这两项入口。
2. **ZCode 体验套餐展示（推荐：对齐上游）**
   采用“单个置顶、无分组、`GLM-5.3-Flash（体验）`”并给回答页脚加 `（体验）` 后缀；否则保留现有 `BigModel (体验)` 分组，只移植同步载荷与发送路由，未来此处仍会反复冲突。
3. **后台任务发送确认框（推荐：恢复上游）**
   回合结束但后台任务仍在跑时，发送先弹“仍要发送 / 排队 / 取消”。这是上游 #1583 的行为，恢复后能消掉每次合并都撞的差异；本仓库的服务端队列、追加、强制发送保持不变。
4. **公开部署的 pnpm 版本（前置检查）**
   上游按 pnpm 11/12 语义把构建白名单移入 `pnpm-workspace.yaml`。部署机必须能运行 pnpm ≥ 11；若仍固定 pnpm 10，需要同时保留 `package.json` 的 `pnpm.onlyBuiltDependencies`，否则 staging 原生依赖可能不被构建。
